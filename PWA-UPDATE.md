# Mise à jour PWA MedConnect

Cette mise à jour ajoute le manifeste installable, le service worker sécurisé, le mode hors connexion, le pack d'icônes et le logo dans l'interface.

Elle ne modifie ni `wrangler.jsonc`, ni l'identifiant D1, ni les routes API.

Après avoir remplacé les fichiers concernés dans GitHub, le déploiement Cloudflare automatique doit démarrer. Une fois terminé, rechargez l'application et testez l'installation depuis Chrome ou Edge. Sur iPhone, utilisez **Partager > Sur l'écran d'accueil**.
